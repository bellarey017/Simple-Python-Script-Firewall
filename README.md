# Simple-Python-Script-Firewall
This python script showcases the concept of network access control through firewall rule enforcement. Though it is simple, it simulates how a firewall evaluates incoming IP addresses against a predefined set of security rules and determines whether the traffic from the IP address should be allowed or blocked. 

The script portrays a real-world defensive security practice used to protect systems from known malicious or unauthorized sources. Additionally, it showcases how cybersecurity professionals can utilize scripting to improve threat detection whilst enforcing security policies.
